# MIE1517Project---CIFAKE-Real-vs-AI-Image-Detection-ViT-B16-
Course project for MIE1517 that fine tunes a pre trained Vision Transformer (ViT B 16) to classify CIFAKE images as real (CIFAR 10) vs AI generated (Stable Diffusion). Best model reaches about 96 to 97 percent test accuracy with strong precision, recall, and F1.
